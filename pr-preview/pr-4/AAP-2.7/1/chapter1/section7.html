Event-Driven Ansible Enhancements

AAP 2.7 introduces significant enhancements to Event-Driven Ansible (EDA) to increase reliability, flexibility, and control.

What’s New in Event-Driven Ansible?

Event Bus Support Improvements

  • New Azure event bus

  • New AWS event bus

  • In-flight rulebook event persistence, providing increased rulebook resiliency

EDA Automation Creation

  • Project synchronization: allow resync option on restarts

  • Rulebook enhancements: Additional jinja filters to replace regular expressions, offering more flexibility

Secrets Management Support

Enhanced design and control for EDA projects and execution:

  • Hashicorp Vault, CyberArk, AWS, Azure and others

  • Editable project source control URLs

  • EDA job labeling for more efficient tracing + auditability

  • Kafka: Multiple topics, extended regular expressions and wildcards

  • New event-splitter for nested events

  • Rulebook concurrency key to group events by resource

  • mTLS support

  • Pull policy parity for decision environments

Operational Updates

  • Streamlined ansible.eda content collection

  • Updated decision environments

New Ansible Content Collections

  • Splunk Enterprise Security: Full support for managing SPLUNK agents and more across the enterprise

  • Splunk IT Service Intelligence: For managing SPLUNK agents and more across the enterprise

  • Splunk enterprise for managing SPLUNK agents and more across the enterprise

  • Microsoft System Center Operations Manager (SCOM) (Azure and windows)

  • Amazon.ai support for DevOps Guru to EDA
