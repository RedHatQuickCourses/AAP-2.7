= Security, Governance, and Identity

Ansible Automation Platform (AAP) 2.7 fundamentally rebuilds the platform’s security architecture by enforcing a strict zero-trust posture and eliminating legacy, high-risk access vectors. By transitioning entirely away from direct component-level API access and unencrypted basic authentication, AAP 2.7 mandates a unified gateway model. 
The platform now introduces native OpenID Connect (OIDC) provider capabilities alongside workload identity frameworks, transforming how users, external applications, and automated playbooks authenticate securely across the enterprise.

== Why Does It Matter?

- *Elimination of Static Credential Sprawl:* Traditional automation often relies on hardcoded passwords or long-lived service account tokens that can easily leak. By utilizing dynamic *OIDC Workload Identities [Tech Preview]*, playbooks generate short-lived, cryptographic identities on the fly—greatly reducing the corporate attack surface.
- *Reduction of the Attack Surface:* Disabling direct, unauthenticated API access to individual components (like the Controller, Hub, or EDA engines) closes legacy backdoors. Attackers can no longer attempt to bypass security layers by hitting standalone component ports directly.
- *Enforced Centralized Auditing:* Forcing all external tools, basic authentication, and personal access tokens through a unified authentication layer means your security team gets a single, untampered audit log of every action taken within the automation fabric.
- *Seamless Secrets Management Integration:* By acting as an OIDC provider, AAP 2.7 allows external systems—specifically HashiCorp Vault—to cryptographically verify that an automated job is exactly who it claims to be before releasing sensitive infrastructure secrets.

*Instructor Tip:* Before running the AAP 2.7 upgrade, execute the new CLI utility aap-detect-direct-component-access. This will automatically scan and pinpoint any legacy, direct-API scripts hidden in your environment so you can fix them before they are blocked.
